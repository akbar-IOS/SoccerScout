# SoccerScout ⚽️

Production-style iOS application built with SwiftUI using MVVM architecture, async/await networking, 
REST API integration, and clean project organization.

## Features

- SwiftUI UI Development
- MVVM Architecture
- REST API Integration
- Async/Await Networking
- Player Search
- Player Detail Screen
- Form Validation
- Error Handling
- Loading States
- Clean Project Organization
- Networking Layer Separation
- Search Functionality

## Technologies

- Swift
- SwiftUI
- URLSession
- Codable
- Async/Await
- ObservableObject
- MVVM
- REST API

## Architecture Concepts

- MVVM Design Pattern
- State Management
- Networking Layer Separation
- Data Flow
- ViewModels
